## v0.3.0 增量（同日，守护进程 + 告警钩子）
- 触发：用户选择「守护进程 + 告警钩子」作为下一步功能
- 交付：`cfgdrift daemon`（start/stop/status，后台常驻定期扫描）+ `cfgdrift alert`（add/list/remove/test，webhook/email/script 三通道）
- 关键文件：新增 src/cfgdrift/daemon/{daemon,worker}.py、src/cfgdrift/alert/{models,config,state,dispatcher,channels}.py；修改 cli.py 追加两 group；版本 0.3.0
- 关键设计决策：
  - Windows daemon 用子进程方案（Popen DETACHED_PROCESS|CREATE_NEW_PROCESS_GROUP|CREATE_NO_WINDOW），免 pywin32；**Windows 禁 os.kill(pid,0)**（会杀进程），用 ctypes OpenProcess(SYNCHRONIZE)
  - stop：POSIX SIGTERM；Windows 哨兵文件 daemon.stop + 超时 taskkill /F 兜底
  - SMTP 密码只存环境变量名（--smtp-password-env），{env:VAR} 统一替换；payload 不含凭据/敏感值
  - 默认：interval=300s、阈值 WARN、冷却 10min、重试 3 次（1s/5s/30s）
  - 去重键 = sha256(rule.name:fingerprint)，指纹不含值
  - alerts.yaml（version:1+rules[]，0600）；alert_state.json（冷却/24h prune）
  - Store 零新增表；扫描历史复用 add_scan(mode="daemon")；web /api/alerts 推迟 P2
- 质量：QA 第 4 轮独立验证 343 passed / 2 skipped，路由 NoOne，无源码 Bug
- 脚本通道 env：CFGDRIFT_EVENT/VERSION/TIMESTAMP/SEVERITY/BASELINE/TARGET/DRIFT_COUNT/SUMMARY/DRIFT_ITEMS_JSON
- 已知限制：POSIX 双 fork 分支未在本机实测（Windows 沙箱，代码路径已审查）；interval 兜底 300s 与 CLI 拦截行为略不一致（R1 非阻塞）
